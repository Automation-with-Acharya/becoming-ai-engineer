# Day 019 Practice: Configuration and Environment Variables

## Exercise 1: Create an Environment File

Create a `.env` file and store the following values:

- App name
- Secret key
- Database URL
- Debug flag

## Exercise 2: Create a Configuration Module

Create a `config.py` file using Pydantic Settings.

## Exercise 3: Read Configuration in the Application

Read configuration values inside `main.py` without hardcoding them.

## Exercise 4: Configure the JWT Secret

Move the JWT secret into the configuration.

## Exercise 5: Configure the Database URL

Move the database URL into the configuration.

## Exercise 6: Use Configuration for Logging

Use configuration values inside logging.

Example:

```env
LOG_LEVEL=
```
